# The Todo App
An offline-first, free and open-source productivity app built 
for people who want complete control over their workflow.

- **Current Version:** 0.0.0

## Platforms
- Android 
- Linux
- Web

## Principles
- Free and open source
- Offline-first 
- Highly customizable
- Optional gamification

## Features
This project is currently in early development.
